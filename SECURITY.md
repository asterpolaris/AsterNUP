# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/asterpolaris/AsterNUP/security/advisories/new), not in a public
issue. Include what's affected, how to reproduce it, and the AsterNUP version. You'll get a reply as soon as possible,
and credit in the release notes if you'd like it.

## Scope

This policy covers AsterNUP itself: the app, its scripts and its installer. Problems in the nxnative backend or in
game apps it builds belong to [nxnative](https://github.com/seedds/nxnative).

Only the latest release is supported with fixes.
